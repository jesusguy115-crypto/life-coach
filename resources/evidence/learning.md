# 图像、感觉与自然学习：按需依据

仅在能力卡不足以回答时补读。以下原创转述保留候选ID、步骤、前提及限度。

<a id="f04"></a>
## f04 已会则允许执行，未会则提供学习

定位：第4章：信任自己；PDF 23–27；PDF 见原候选定位；判定：verified。

先区分技能已经建立还是尚待学习；前者减少逐步干预，后者通过示范和实际接触建立经验，同时由意识明确任务目标。

方法步骤：确认是否有完成类似动作的经验；明确所要结果；已会时允许动作运行；未会时提供示范和尝试；观察结果以补充经验。

需要材料：目标；既有技能证据；当前经验与可用示范。

完成结果：执行模式或学习模式的安排。

限度：原文未给技能成熟度量表；放手不保证新手胜任；危险或高代价任务不能照搬随意试错。

执行去向：cards/learning.md；walkthrough：从未握拍的新手要求直接放手 → 选择学习分支，提供示范、接触球和反馈；不许诺自动掌握。


<a id="f05"></a>
## f05 观察示范—形成影像—模仿感受

定位：第1章 PDF 3–4；第4章 PDF 25–27；第5章 PDF 38；PDF 见原候选定位；判定：verified。

先吸收完整动作的视觉节奏，再想象自己执行并尝试，交替看与感受，避免把完整动作拆成执行时不停回放的文字口令。

方法步骤：观看完整示范；在心中重现；让身体模仿；感受动作；再看再试。

需要材料：有效示范；可观察环境；练习机会。

完成结果：动作影像；初次模仿及感觉反馈。

限度：初例教练仍帮助握拍；示范须适合学习者；原文未规定各类任务的练习剂量。

执行去向：cards/learning.md；walkthrough：新手已有教练握拍帮助和正手示范 → 完整观看、形成影像、尝试并报告动作感觉，再看再试。


<a id="f06"></a>
## f06 用结果影像传达目标

定位：第4章：结果编程；PDF 27–28；第5章 PDF 40；PDF 见原候选定位；判定：verified。

把注意力从多项动作规定移到具体结果，形成球路和落点影像，再允许身体尝试并观察实际结果；作者尤其建议用于比赛。

方法步骤：把抱怨转换成想要的结果；想象实现结果的轨迹；保持影像片刻；执行时不追加动作口令；看实际落点并继续尝试。

需要材料：明确结果；可想象的目标轨迹；已有基本执行能力。

完成结果：结果影像；实际结果记录。

限度：比赛不能替代此前的技能学习；连续无进展可转动作示范；目标影像不是成功保证。

执行去向：cards/learning.md；walkthrough：已有正手基础，想让回球更深 → 明确落点和弧线影像，执行时少加口令，观察实际深度。


<a id="f07"></a>
## f07 观察和结果目标不足时转入动作影像

定位：第4章：动作编程；PDF 28–31；PDF 见原候选定位；判定：verified。

对持续不变的动作，先给出清楚的视觉及身体感觉模板，然后让动作发生；结果仍偏离模板时重新呈现，而非在执行中施加更多口令。

方法步骤：确认单纯观察或结果目标未足够奏效；看清目标姿态；想象完整运动；慢做并感受；实际执行；比较偏差后必要时重新示范。

需要材料：待改变动作；正确示范或目标姿态；当前反馈。

完成结果：动作模板及其对应结果。

限度：正确模板来源须可靠；文本技术图缺失；原文未给无效尝试次数上限。

执行去向：cards/learning.md；walkthrough：观察及落点影像无进展，已有可靠随挥示范 → 看姿态、想完整动作、空挥感受、实际尝试、偏离时再示范。


<a id="f08"></a>
## f08 对照实验识别控制与允许的差别

定位：第4章：两个实验；PDF 29–31；PDF 见原候选定位；判定：verified。

通过两种执行方式的实际体验建立区别，记录紧张、动作和结果，而不是只认同理论；进一步回到对打与比赛检查能否延续。

方法步骤：体验惯常强行纠正；记录感觉和结果；观察当前动作；提供目标影像或动作感觉；减少指令后再试；在对打中检验。

需要材料：可重复且低风险任务；目标；喂球伙伴或结果反馈。

完成结果：两种尝试的感受与结果差异；转入对打后的表现。

限度：两实验条件并不严格等同；不能据一次对照证明普遍因果；技术熟悉度和练习效应可能影响结果。

执行去向：cards/learning.md；walkthrough：熟练球员可在低风险环境重复打同一目标 → 分别体验强控与目标影像后的执行，比较感觉和结果；不作严谨因果结论。


<a id="f09"></a>
## f09 通过角色试演扩展表现范围

定位：第4章：身份编程与角色扮演；PDF 31–32；第5章 PDF 37；PDF 见原候选定位；判定：verified。

明确是试演一个角色，短时采用其姿态与行动方式以探索被固定自我形象压住的表现；无需相信自己已经成为该角色。

方法步骤：辨认惯常风格；选择一个不同的角色；明确这是试演；以该角色姿态进行动作；观察出现的不同能力。

需要材料：习惯性风格；想探索的另一风格；练习情境。

完成结果：新行为体验；可表现范围的认识。

限度：不等于积极暗示或人格改造；原文没有维持时长或后续巩固方案；不能保证风格适用于每场比赛。

执行去向：cards/learning.md；walkthrough：习惯保守的球员希望探索更主动风格 → 在练习中短时试演主动球员姿态，观察行为差别，不宣称变成人格。

## f10 用关键动作观察点简化技术学习

定位：第5章：技术要点；PDF 33–37；PDF 见原候选定位；判定：verified。

将外部任务简化为必须满足的结果条件，再寻找少数会影响多个细节的关键动作，以观察点而非强制口令使用技术知识。

方法步骤：明确任务必须满足的结果；找关键动作关系；一次观察一项；记录真实动作和结果；允许个人节奏形成。

需要材料：外部任务约束；有依据的关键技术要点；当前动作。

完成结果：一次一个的关键观察对象。

限度：原书具体技术不是现行专业标准；主次元素需要领域知识判定；缺失图示不能补画为已核验动作。

执行去向：cards/learning.md；walkthrough：教练已提供可靠关键点，学员一次想改五项 → 按外部目标选择一个关键观察点；缺领域依据时请求示范，不自创技术标准。


<a id="p43"></a>
## p43 不强控不等于松垮无力

定位：内在比赛的学习方式；PDF [45, 46, 74]；判定：verified。

减少有意识的逐肌肉操控，同时保留完成任务需要的能量、坚定和全力投入。

条件：不将本书理解为越少实际努力越好。。

主张属性：可执行指导。

执行去向：cards/learning.md；walkthrough：学员把放手理解为不用力 → 区分必要击球投入与多余控制，仍保留完成动作所需能量。


<a id="p73"></a>
## p73 教学者也观察自己如何学习

定位：从经验学习；PDF [85]；判定：verified。

教练不只检查学生动作，也从学生反应认识学习过程，并检验自己是否仍在学习。

条件：作者认为教师应至少学到同样多是自我要求，不是可量化职业淘汰标准。。

主张属性：可执行指导与作者格言。

执行去向：cards/learning.md；walkthrough：教练纠错越多学生越紧张 → 观察自己说话与学生反应，改变信息呈现并继续看反馈。
