# 不加评判地观察：按需依据

仅在能力卡不足以回答时补读。以下原创转述保留候选ID、步骤、前提及限度。

<a id="f01"></a>
## f01 指挥活动与执行活动的关系模型

定位：第2章：发现两种自我；PDF 5–8；第10章总结 PDF 75；PDF 见原候选定位；判定：verified。

将当下的指令、评价和实际执行分开观察，检验反复指挥是否伴随额外紧张或注意力转移；这是作者解释表现受干扰的模型。

方法步骤：找出正在告诉自己什么；记录执行时注意力和紧张变化；区分完成任务的努力与额外监控；对照少指令时的实际表现。

需要材料：一次具体表现过程；当时的自我话语；动作或任务表现。

完成结果：指令与执行及反馈之间的关系描述。

限度：模型不是人格或脑区诊断；原文强因果断言缺少系统实验；无法仅凭失误断言存在过度控制。

执行去向：cards/observe.md；walkthrough：熟练发球者反复提醒手腕位置并感到僵硬 → 分开口令、握持感与落点；少一条口令再观察，不把失误单因归于头脑。


<a id="f02"></a>
## f02 事件—评价—自我定性的扩展链

定位：第3章：让头脑安静；PDF 10–13；第10章 PDF 77–78；PDF 见原候选定位；判定：verified。

观察一次事件如何被概括为一类表现，继而被当作身份结论；用可描述的事实截断扩展，同时保留误差和改进信息。

方法步骤：定位单次事件；标出好坏评价；检查是否扩展到总是或整个自我；改用数量位置时间等描述；保留需要改变的具体结果。

需要材料：原事件；用户原话；可核实的表现记录。

完成结果：事实与附加评价的区分；范围受限的描述。

限度：不是用积极定性替换消极定性；不否认真实损失；作者未提供所有语言场景的判断标准。

执行去向：cards/observe.md；walkthrough：两次发球出界后说我什么都做不好 → 保留两次出界事实，标出从本次到整个人的推断。


<a id="f03"></a>
## f03 以感知观察替代纠错口令

定位：第3章：观察实际发生什么；PDF 14–17；PDF 见原候选定位；判定：verified。

选定一个具体时刻与可感知变量，让学习者先报告实际位置或感觉；若回答仍是好坏、早晚标准，再回到原观察对象。

方法步骤：选一个观察点；暂停纠正并重复动作；询问精确位置或感觉；将评价性回答引回事实；继续观察自然发生的变化。

需要材料：具体动作；可观察变量；可重复尝试或镜面反馈。

完成结果：真实动作感知；观察过程中的变化。

限度：用户须能获得真实反馈；书中没有保证观察必然足够；镜面视觉可转为动作感觉但跨任务迁移需验证。

执行去向：cards/observe.md；walkthrough：学员只说引拍太差，能看到回放 → 定位球落地帧的拍头位置；把好坏回答改成位置描述。


<a id="p10"></a>
## p10 不把肯定性评价当成观察的替代品

定位：关于积极思考；PDF [17, 18, 19, 79, 80]；判定：verified。

当称赞制造出必须保持优秀的压力时，回到事实反馈；不以反复宣称自己很强或处境很好来覆盖实际困难。

条件：作者讨论表现练习中的评价干扰；不能推导为所有鼓励、赞赏或正面想法都无用。。

主张属性：可执行指导；作者对正负评价不可分离的普遍化为强断言。

执行去向：cards/observe.md；walkthrough：被夸一次后担心下次维持不住 → 改用具体表现反馈，不用另一句积极身份评价覆盖压力。


<a id="p11"></a>
## p11 用已经发生的协调能力建立尊重

定位：信任自己；PDF [21, 22]；判定：verified。

注意身体已能完成的阅读、走路和击球协调，用真实经验削弱对自己笨拙无能的笼统结论。

条件：原文神经系统与计算机容量的论证是年代性说明，不作为现代科学定量证据。。

主张属性：可执行指导。

执行去向：cards/observe.md；walkthrough：用户说自己身体什么都做不好但能稳定完成熟悉动作 → 用已发生的协调事实限制笼统定性，不推导未学技能已掌握。


<a id="p13"></a>
## p13 不把动作表现视为自己的全部

定位：信任自己；PDF [24]；判定：verified。

对学习中的动作保持关心与耐心，但不要让每次成败都决定自我价值；像关注正在发展的能力一样关注它。

条件：作者关于人不是身体的说法属哲学背景；可执行部分仅是与表现标签保持距离。。

主张属性：可执行指导与哲学立场混合。

执行去向：cards/observe.md；walkthrough：学习一次动作失败即否定自我价值 → 关注动作发展的具体困难，停止用结果判定整个人。
