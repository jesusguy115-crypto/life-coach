# 多项命中时，先用哪种方法

本提案基于现有七卡，属于产品决策规则，不冒充书中原有分类或原句。

## 先判断是否该用，再决定先用哪个

1. 先处理显式急务、安全或健康诉求；只有失业、失眠、焦虑等标签，不足以推出内在干扰。范围不匹配时指出具体限制，必要时询问一个关键事实，不强派练习。
2. 找用户本轮希望改变的事情及一个具体片段。材料够就直接给适当回应；不把完整心理访谈当入口。缺失信息会改变主方法时，仅问一个问题。
3. 主方法取决于**当前阻碍用户下一步的环节**。用户只想理解，就解释；想改变且条件明晰，才提出一次可反馈尝试。不要把词频、情绪强度或书章节先后当优先级。
4. 一次以一张卡为主。第二张只补充当前主方法缺的步骤，不连续给两套练习；不能确定时允许 clarify，不能为了覆盖率强选。

## 可执行判据

| 当前能确认的材料 | 主方法 | 区分依据 |
|---|---|---|
| 只有“我很差/总失败”总评，事实不清，用户要理解问题 | observe | 先获得一条可核对事实；不是因为出现了“自责”这个词 |
| 重复行为、触发时刻和结果已清楚，用户要改变它 | habit | 自责可附带存在；无需先完整走一次自责辅导 |
| 初学/缺示范/要求不清；或已有经验但同步口令妨碍执行 | learning | 先识别输入缺口或过度控制；紧张不等于熟练，不默认能力已具备 |
| 任务和意图清楚，只是接收/表达被注意漂移打断 | attention | 返回与任务有关的信息；不让过度监听者更细听自己 |
| 核心问题是还想不想参与、为谁参与、参与代价 | motives | 尊重获利、胜利、资格等现实目的，不一律劝享受过程 |
| 有公平、自愿、具体竞争，困惑是如何认真争胜又不以成败定义自己 | competition | 若是欺凌、不公平、强迫，停止体育类比 |
| 可指出过去重播/未来推演的具体链条，且反复思考没有新信息并挤占当前行动 | future | 仍保留真实风险与有用规划；只有病症或生活处境不适用 |

## 常见冲突怎么选

- **自责 + 重复行为**：事实未清 → observe；过程已清、要换做法 → habit。自责出现在改变过程里可用一句非评判观察，不必换主卡。示例：“每写一句就回头删，删完安心又继续删”已给过程，habit 优先。
- **过控 + 分心**：连续纠正执行方式导致卡住 → learning；意图已清但注意被别处拉走 → attention。不是按是否出现“想太多”分。
- **初学 + 自责**：用户明说缺输入并要求如何学习 → learning；不必先教“相信自己已经会”。用户仅问一次失败是否意味着自己笨 → observe，随后识别学习缺口。
- **未来担忧 + 自我否定**：反复推演正在阻断眼前任务 → future；只剩人格总评、缺具体事件 → observe。不能见到自我标签就切换主方法。
- **动机 + 竞争**：在问“还要不要/为什么参加” → motives；已决定参赛、问怎样全力以赴 → competition。
- **反复行为 + 必要检查**：先核对行为功能与要求；有明确安全制度的检查不能削减。若没有额外无效重复，非 habit 纠正对象。
- **方法失败**：优先处理反馈并撤回不适合的练习，再判断路由；不要把“失败”自动路由 observe，也不要继续加码原方法。
