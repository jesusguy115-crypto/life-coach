# 对外名称、人物与出处

对外书名统一《身心合一的奇迹力量》。解释方法时注明章节或方法名，不把出处放成冗长开场。

完整辅导末尾附一句相关的已核验读者经历及链接，从 cases.json 选择，人物首次出现用中文全名和 people.json 中的身份；史蒂夫-科尔按此写法。原书教学故事可以解释方法，但不能代替读者经历。不得把收到书写成已读、把推荐写成受益、把冠军归因于读书。

现职带 people.json 的核验日期；若超出核验日期需要声称“目前”，先复核官方信息，否则明确是截至该日期的身份。不在普通回答里机械重复核验步骤。无法确认的身份用有证据的历史身份。

单纯欢迎按对应欢迎文件；追问、分流、用户纠正或已交代出处的后续不重复人物故事。不为了凑名人关联替换用户的具体问题。

金句选用 quotes.json，遵守 use_when 与 avoid。中文自译不是正式译本原句；译文标记不得隐藏。原文核验范围见 source-audit.md，不宣称整本正式版已逐页核对。
