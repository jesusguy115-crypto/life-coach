# 原书方法与本skill能提供的帮助

本表由原书及全87页复核得到，书评只提供应用观察，不决定能力。页码指当前87页重排PDF；2024新增材料未读。以下是可开展的帮助，不是疗效保证。

| 本书帮助 | 原文依据与机制 | 对话中实际提供什么 | 不承诺什么 |
|---|---|---|---|
| 从错误中学习，不只责骂自己 | 第三章8–21；事件、身份评价、直接感知有别 | 找到一条可核对反馈；教学时让对方看见实际发生什么 | 不否认错误、不保证仅观察就纠正 |
| 学习或执行时减少无效控制 | 第四章25–31；明确意图、学习输入与执行分工 | 区分缺输入与过度干预，使用用户已有目标和反馈尝试 | 不教具体技术，不声称新人本来就会 |
| 理解反复行为并试新的做法 | 第六章41–47；功能与四步学习循环 | 看旧方式满足什么，选择新方式并对照真实结果 | 不编心理根源，不保证习惯形成 |
| 更投入地做事与体验 | 第七章48–61、第十章84–85；兴趣吸引注意 | 选择任务相关对象，观察更能接触信息还是添负担 | 不要求零杂念，不等于不用思考 |
| 找到自己真正愿意投入的目的 | 第八章61–69；动机冲突与价值判断 | 由本人选择想赢、学习、乐趣、联系等目的 | 不替人规定高尚目标，不消除现实代价 |
| 认真竞争，不拿输赢给人定价 | 第九章70–75；投入与结果依附的区别 | 保留求胜、应对挑战，分别看结果与投入 | 不美化恶意竞争，不承诺获胜 |
| 从过去未来或烦扰回到现实 | 第十章77–81；事件与反应、改变环境也可行 | 看清已知和推演，返回当前信息或确认方法不适配 | 不治失眠，不解决就业经济问题 |

这些不是七种互不相关的症状：观察支持学习，注意支持执行，反馈修正尝试，动机决定为什么参与。帮助别人学习可经observe进入，不另造管理学。
作者第十章76、81–82页把意义扩展到自我认识和不再强迫改造自己。skill不能把每次参与都变成改善绩效的新考核。Self3及普遍潜能/自动迁移的哲学主张保留为背景，不能编为能力承诺。
