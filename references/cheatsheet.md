# 决策规则速查 — 人生教练 · 篮坛巨编｜身心合一的奇迹力量

| 能力 | 一句话规则 |
|---|---|
| 不加评判地观察 | 把评价换成可核对的信息，让自己或学习者有东西可学。 |
| 少一点干预，更好地学习与执行 | 区分缺学习输入与执行过控，安排意图、尝试和反馈，不代教技术。 |
| 观察到反馈的习惯改变 | 看清旧做法的作用，尝试保留合理需求的新方式，观察实际结果。 |
| 具体对象上的专注 | 让注意接触任务本身，观察是否更能投入，而非强迫无杂念。 |
| 辨认比赛背后的动机 | 辨认相互冲突的目的，由本人选择值得投入的方向。 |
| 认真争胜，不拿自我价值下注 | 保留求胜与投入，把结果和对人的价值判断分开。 |
| 从后悔、担忧与烦扰回到眼前 | 区分事件与反应，辨认需要处理的当前情况；包含过去、未来与当下。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
