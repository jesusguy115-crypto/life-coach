# 术语表

作者概念的中文转述。Self 1/2不是两个真实人格或脑区，Self 3为哲学背景；现代医学与神经科学效力不由本书支持。

<a id="g01"></a>
## g01 内在比赛／外在比赛（Inner Game / Outer Game）

PDF [1, 75, 76]；开篇；场外应用。

外在比赛面对外部对手、障碍和目标；内在比赛处理注意力涣散、紧张、自我怀疑与自我谴责等妨碍表现的内在活动。后段把内在技能本身也视为练习的价值。

辨别：不是把现实问题都解释成心态问题，也不是只在脑中想象获胜；外部技能和障碍仍然存在。

用途：辅导需辨认当前干扰发生在哪里，不能用内在练习替代必要的技术学习或现实行动。

<a id="g02"></a>
## g02 自我1（Self 1）

PDF [6, 25, 27]；两个自我；信任自己。

作者给有意识的指令者、评价者起的名字；它会指挥动作、判断结果，也能够设定目标、提供示范和向自我2传达意图。

辨别：不是一个真实人格或独立脑区；也不等于所有思考都是坏事。作者保留其设定目标与提供学习材料的合作功能。

用途：避免把减少干扰误教为停止思考、消灭自我或放弃计划。

<a id="g03"></a>
## g03 自我2（Self 2）

PDF [6, 22, 25]；两个自我；信任自己。

执行动作和从经验中学习的一面，包括身体、脑、记忆和神经系统；从看见、感觉到的动作及其结果中获得信息，逐渐形成协调能力。

辨别：不只是肌肉或神秘直觉，也不是无须训练便已掌握一切的隐藏高手。作者明确区分已经会做时让它做、尚未学会时让它学习。

用途：决定应减少对熟练动作的干预，还是安排示范、尝试与反馈；不能向新手许诺放松就会。

<a id="g04"></a>
## g04 评判（Judgment）

PDF [11, 12, 19]；平静头脑。

对事件附加自己喜欢或不喜欢的好坏价值；可能从一次动作扩展成对整类表现、再对自己的定性。作者讨论的正面评判也可能引起自我监控和压力。

辨别：不等于一切判断或评价。判定球出界、统计成功率、发现原因，仍可属于准确观察；附加好坏与个人价值标签才是此处重点。

用途：让辅导保留事实辨别与改进标准，避免把用户的任何看法都叫作评判。

<a id="g05"></a>
## g05 不加评判的觉察（Nonjudgmental Awareness）

PDF [12, 13, 19, 46]；平静头脑；改变习惯。

对正在发生的动作、感觉和结果保持有兴趣的准确观察，不额外添加好坏或自我身份结论；可以看到失误、描述不稳定并探究其原因。

辨别：不是忽视错误、假装满意、机械换成积极措辞或漠不关心；不评判的要求也不应用来批判自己又在评判。

用途：是把模糊自责转为可观察事实、并让反馈进入学习过程的共用基础。

<a id="g06"></a>
## g06 信任自己／让它发生（Trust Thyself / Let It Happen）

PDF [23, 25, 46, 47]；信任自己；改变习惯。

明确目标并提供必要经验后，允许身体执行、犯错和学习，通过观察结果了解其能力，减少逐动作的有意识操纵。

辨别：不是预测每次都会成功、积极暗示、身体松垮或无所作为。信任应在尝试中核验，初学者仍需要学习输入。

用途：防止把书中方法简化成放手不管；练习仍须具备目标、机会、反馈与调整。

<a id="g07"></a>
## g07 过度使劲与实际用力（Trying Hard / Effort）

PDF [8, 23, 46, 74]；两个自我；改变习惯；竞争。

前者指自我1为控制或证明表现而施加的干预，例如重复口令、多余肌肉紧张；后者是自我2完成任务所必需的能量。全力投入可以同时包含专注、决心和对身体的信任。

辨别：不是努力与懒惰之分，更不是所有高强度努力都无效；应辨别必要投入和额外干扰。

用途：避免把不必过度控制误译成不必练习、不必认真或不必争取胜利。

<a id="g08"></a>
## g08 编程（Programming）

PDF [27, 28, 29, 31, 32]；信任自己。

用感官图像和动作感觉向自我2传达意图。作者区分以落点等结果为目标、以动作形式为示范，以及暂时扮演某种球员风格来探索表现的三种方式。

辨别：是沟通目标的比喻，不是计算机代码、灌输必胜信念或单靠视觉化改变现实；角色尝试也不是认定自己已具备未学会的技能。

用途：让目标成为可看见、可感受、可尝试的输入，减少重复抽象命令；结果和动作形式的输入不宜混淆。

<a id="g09"></a>
## g09 动作沟槽（Groove / Grooving）

PDF [41, 42, 43, 47]；改变习惯。

反复动作形成、倾向自动重现的行为模式；作者借唱片沟槽比喻习惯，主张观察旧模式所起的作用，并尝试更好地满足同一功能的新模式。

辨别：不是不可改变的命运，也不是已被本书证明的精确神经结构。形成新模式不等于必须先靠意志根除旧模式。

用途：避免把练习设计成与坏习惯持续搏斗；改为确认功能、提供替代动作并观察是否逐渐自动化。

<a id="g10"></a>
## g10 专注／放松的专注（Concentration / Relaxed Concentration）

PDF [49, 50, 56, 57, 59, 60]；专注。

将注意力置于此时此地的具体对象，以看、听或感觉深入接触它；分心后温和返回。网球中可取球缝、轨迹、击球声、动作感觉等对象。

辨别：不等于用力命令自己集中，也不是思考关于对象的知识、监视自己是否专注或强迫清空念头。放松指减少多余紧张，不是降低感知与投入。

用途：注意力练习必须有具体对象；选择适合当前任务的一个对象，不能一次塞入许多监控要求。

<a id="g11"></a>
## g11 真正的竞争（True Competition）

PDF [73, 74, 75]；竞争的意义。

双方尽力为彼此提供有挑战性的障碍，通过克服障碍发现和拓展能力；胜负仍然存在，但过程的价值不必依赖击败别人来证明个人价值。

辨别：不等于让球、取消取胜愿望或断言现实竞争总是双赢；是作者对竞技互动的一种价值理解。

用途：重构竞争时仍保留具体目标和充分投入，不把输赢与人的价值合并，也不美化现实中的伤害。

<a id="g12"></a>
## g12 心绪慌乱／临变不乱（Freak-out / Unfreakability）

PDF [77, 78, 79, 80]；场外应用。

前者指头脑因过去遗憾、未来忧惧或不喜欢当前处境而扰乱，以致难以看清并恰当行动；后者指变化中仍能辨认实际发生之事、作出合适回应的能力。

辨别：是本书日常用语，不是精神疾病名称。镇定不是否认危险或不关心；区分事件和反应不等于外部问题不存在。

用途：面对担忧时，需要分清当前事实、未来推演与能采取的行动，避免把现实困难归咎于用户心态。

<a id="g13"></a>
## g13 执著（Attachment）

PDF [81, 82]；场外应用。

作者指把内心安定过度系于特定事物、处境、人物或观念，并紧抓、试图控制它们，因此在变化发生或将发生时陷入慌乱。

辨别：不等于拥有财物、珍惜关系或承担责任；放下在此指松开控制性的抓握，不必解释为舍弃对象。作者关于所有慌乱根源的概括应保留为其观点。

用途：供理解后段生活推广时使用，不据此要求用户离开关系、放弃权益或否认真实需求。

<a id="g14"></a>
## g14 自我3（Self 3）

PDF [86, 87]；全书结尾的内在探索。

作者在结尾暂以此名指可被直接体验的内在生命本源，并把它与爱、真、美及潜能联系起来；属于其个人精神探索的陈述。

辨别：不与自我1、自我2组成已验证的心理学三分模型；不是第三个人格、脑区、诊断类别或必须达到的治疗阶段。

用途：忠实保留全书后段语境，同时阻止下游辅导把作者的哲学体验包装成科学事实或操作性疗法。
