# 身心合一的奇迹力量

这是篮坛巨编依据 W. Timothy Gallwey《身心合一的奇迹力量》制作的辅导工具。它帮助你看清学习和发挥时的心理干扰，尝试减少自责、过度控制和分心，也陪你弄清自己为什么投入一件事。

**你可以从下面七个入口开始。** 这是按书中方法整理的使用目录，括号内是对应章节。

1. **一出错就责怪自己，怎样才能真正学到东西？** 先观察具体发生了什么，把事实和对自己的评价分开，让错误成为可用的反馈。（第3章，不加评判地观察）
2. **越想做好，反而越做不好，怎么办？** 分清哪些地方还需要学习，哪些地方已经被反复提醒和控制打乱；明确想做什么，再通过尝试和反馈学习。（第2、4章，两个自我与信任学习能力）
3. **反复提醒自己改，为什么还是老样子？** 看清旧习惯怎样发生、起了什么作用，再经历观察、明确改变意图、尝试和检验结果的过程。（第6章，改变习惯）
4. **做事时总走神，怎样把注意力放回来？** 找到眼前值得留意的具体内容，通过观察和兴趣练习专注。（第7章，专注）
5. **原本喜欢的事，怎么变得只剩压力？** 看看自己如今追求的是乐趣、进步、认可还是证明自己，再决定愿意为什么投入。（第8章，辨认参与的动机）
6. **很想赢，又怕输得丢脸，怎样才能放开去做？** 把竞争看作检验和发展能力的机会，保留争胜的认真，同时把比赛结果与个人价值分开。（第9章，竞争的意义）
7. **总在后悔过去、担心以后，怎样回到眼前？** 分清已经发生的事、对未来的推演和自己此刻的反应，把注意力带回当前需要面对的情况。（第10章，球场之外的内在比赛）

这里提供的是观察、学习和应对心理干扰的方法。具体技术仍需要相应的学习与指导；就业、经济和健康问题，也需要各自的现实支持。

**为什么篮球迷值得认识这本网球书？**

史蒂夫-科尔（金州勇士队主教练）在公牛打球时，常因短暂上场机会中的投篮得失承受压力。据《体育画报》2016年的采访，他反复读这本书、做笔记，每个休赛期重读，还常备多本赠人。他尝试减少对表现的即时评判，执教时也减少过多口头指令。推荐这本书给他的，是投篮教练奇普·英格兰德（休斯敦火箭队助理教练，专长为投篮指导）。[采访来源](https://www.si.com/nba/2016/05/26/steve-kerr-pete-carroll-nba-playoffs-inner-game-tennis-book)

还有这些值得了解的读者和推荐者：

- **萨姆·普雷斯蒂（俄克拉荷马城雷霆队执行副总裁兼总经理）**：在同一采访中说自己反复阅读，把喜欢的段落整理成文档，也把书给员工读。他重视的是留意眼前，而非一直回想过去或预想以后。
- **保罗·韦斯特海德（前 NBA、WNBA 主教练，2026年查克·戴利终身成就奖得主）**：报道将本书列为这位 NBA 教练最喜欢的两本书之一。
- **格兰特·希尔（美国男篮国家队总经理、前 NBA 球员）**：据奇普·英格兰德回忆，他收到书后经常查阅。这是阅读记录，不能据此说他公开推荐过。[以上人物来源](https://www.si.com/nba/2016/05/26/steve-kerr-pete-carroll-nba-playoffs-inner-game-tennis-book)
- **比尔·盖茨（微软联合创始人、盖茨基金会主席）**：在2022年的书评中称它为自己读过最好的网球书，并表示仍会送给朋友。他特别谈到，失误后的自责会拖累下一分，而本书帮助他理解怎样放下这些负面反应。[本人书评](https://www.gatesnotes.com/meet-bill/games-i-love/reader)

这些经历说明他们为什么重视这本书；这个工具会根据你的具体情况选择方法，不保证复制他们的体验。

**你可以选一个编号，也可以直接讲最近的一件事。我会说明用到书里的哪种方法；形成具体建议后，会附上一张可保存的建议卡。**

## 安装与调用

将本仓库链接交给支持 Agent Skills 安装的工具，请它安装仓库根目录 SKILL.md 对应的 skill。也可完整克隆到工具的 skills 目录，文件夹名为 life-coach。请保留所有资料和模板，不要只复制 SKILL.md。

安装后输入“身心合一的奇迹力量”，或直接描述困扰。生成页卡需要 Python 3，仅使用标准库；保存图片需要浏览器支持 JavaScript。
